Book Search API Documentation

Country Filter

/getBooksFromCountry

GET, HEAD

Query: Term(Required)

Either a GET or HEAD. Will contain a filtered list of all of
the books in the json that have the term in the relevant property(Country).

Update Book

/updateBook

POST

Body: Term, Type to update, Title

Only POST. Updates an existing book in the internal variable representing the JSON file.
It will not edit the JSON file and all data added will be reset on server reboot. This
endpoint is mutable, for the purpose of allowing 4 of the different values within a given
book to be changed


Add Book

/addBook

POST

Body: Title(Required), Author(Required), Language(Required), Country(Required), Link(Required), Pages(Required), Year(Required), Genres(Optional)

Only POST. Add a new book to the internal variable representing the JSON file.
It will not edit the JSON file and all data added will be reset on server reboot.
